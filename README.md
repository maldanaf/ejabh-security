# Ejabh Security

إضافة حماية لووردبريس بواجهة عربية، بُنيت بعد التعامل مع اختراق حقيقي، وتركّز على ما يفعله المخترقون فعلاً: الأبواب الخلفية، الشِلّات الرافعة للملفات، صفحات التصيّد، وحسابات المدير المزروعة.

A WordPress hardening plugin (Arabic admin UI) focused on what attackers actually do: backdoors, uploader shells, phishing pages and planted admin accounts.

**المتطلبات:** ووردبريس 6.4 أو أحدث (مُختبرة حتى 7.0)، PHP 7.4 أو أحدث.

## التثبيت

1. نزّل `ejabh-security.zip` من [آخر إصدار](../../releases/latest).
2. من لوحة التحكم: الإضافات ← أضف جديداً ← رفع إضافة.
3. فعّلها. التحديثات التالية تصل وتُثبَّت تلقائياً.

> **قبل التفعيل:** تأكد أن الموقع يرسل البريد (SMTP). المصادقة الثنائية تعتمد عليه.
> إن حُبست خارج الموقع، أضف `define( 'EJABH_SEC_2FA_BYPASS', true );` إلى wp-config.php، ادخل وأصلح المشكلة، ثم احذف السطر.

## ما الذي تفعله

| | |
|---|---|
| **الدخول** | مصادقة ثنائية إجبارية بالبريد، حدّ لمحاولات الدخول وحظر العناوين، تنبيه عند الدخول من عنوان جديد، عرض الجلسات النشطة وإنهاؤها، منع كشف أسماء المستخدمين |
| **الحسابات** | منع إنشاء حسابات مدير خارج القائمة المعتمدة، وكشف كلمات المرور المكتوبة مباشرة في قاعدة البيانات (MD5) |
| **الإضافات** | حظر إضافات مدير الملفات وحذفها، وقصر تثبيت الإضافات والقوالب على حساب مالك واحد |
| **الفحص** | فحص كامل للملفات مع التحقق من بصمات ووردبريس الرسمية، تدقيق نزاهة الإضافات، فحص قاعدة البيانات، ومراقبة تغيّر الملفات |
| **الحماية الفورية** | اعتراض الملفات الخبيثة لحظة رفعها قبل أن تصل لأي إضافة، ومراقب كل ٥ دقائق يحجر الشِلّات وصفحات التصيّد التي تظهر على السيرفر |
| **التحصين** | إصلاحات بنقرة: مفاتيح الأمان، ثوابت wp-config، قواعد .htaccess، مفاتيح الذكاء الاصطناعي في ووردبريس 7، واجهة Abilities |
| **التقارير** | تنبيهات فورية وتقرير أمان يومي لعدة مستلمين، وتقرير HTML قابل للتصدير |

الملفات المطابقة حرفياً للنسخ الرسمية من wordpress.org لا تُمسّ أبداً. القواعد التي يُتخذ بها إجراء تلقائي مختبرة على نحو 20 ألف ملف حقيقي دون أي إنذار خاطئ.

## التحديثات الموقّعة

كل إصدار يُوقَّع بمفتاح Ed25519 لا يغادر جهاز المطوّر. الإضافة ترفض أي حزمة تحديث لا يتطابق توقيعها مع المفتاح العام المضمّن فيها، لذلك لا يستطيع من يخترق هذا المستودع وحده دفع كود إلى المواقع.

### نشر إصدار جديد (للمطوّر)

```bash
# 1. حدّث رقم الإصدار في ejabh-security.php (في الترويسة وفي EJABH_SEC_VERSION)
# 2. git commit
bin/release.sh "ما الذي تغيّر"
```

يحتاج السكربت [GitHub CLI](https://cli.github.com/) ومفتاح التوقيع في `~/.ejabh-security/release-signing.key`.
